Majority of the project is structured automatically by IntelliJ specifically for Java/Maven projects. Some content was auto-generated by dependencies such as Vaadin.

```
csci2040-final-project/
├──docs/
│   ├──dev/
│   └──user/
├──images/
│   └──UML/
├──src/
│   ├──main/
│   │   ├──bundles/
│   │   ├──frontend/
│   │   ├──java/
│   │   └──resources/
│   └──test/
├──target/
├──.gitignore
├──movies.csv
├──pom.xml
├──README.md
```

**Note:** The `target/` directory is not pushed to the remote as it is generated by IntelliJ/Maven when the project is run or built in any way.
