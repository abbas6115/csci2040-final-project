## Is an Internet connection required to use *Filmbase*?

Yes, since it is a web-application, users will need an Internet connection and a supporting browser to access and use Filmbase.

## Where is data stored?

Both user/admin and movie data are stored live in the application; the movie "database" is a repository interface built with the Java Spring Framework. A CSV file is also used to store movie data.

## What devices can users access Filmbase on?

Any device that has an Internet connection and an up-to-date web browser.

## How can the application be stopped?

To stop the application and close the webserver, simply go to the terminal where Filmbase is running and press `Ctrl + C`.

## Why won't the run command for the app work in my terminal?

Ensure you are in the correct directory and have Java **21** installed.
