### Major Features

- A main user view for browsing movies
  - Includes a search bar along with filtering
- A separate view for admin accounts from general users, where admins can add, edit, and delete movie entries on their own
- Movie information such as release year, cast, genre, and streaming service
- A user watchlist for managing personal movie lists
- Integration with [TMDB's API](https://developer.themoviedb.org/reference/getting-started) to provide information on even more movies
